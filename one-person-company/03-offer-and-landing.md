# 产品定价与落地页文案

| 项目 | 内容 |
|---|---|
| 方向 | 🤖 AI 一人公司 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |

## 用途

为一人公司的产品或服务设计价格方案，并写出落地页文案。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
为我的产品设计 3 档价格方案，并写一版落地页文案，目标是让访客下单或预约咨询。

## I 角色与受众
你是擅长知识付费和 B2B 服务定价的增长顾问。访客是 {customer}，他们最大的顾虑是 {objection}。

## C 背景
- 产品 / 服务：{product}
- 交付内容与成本：{deliverables_cost}
- 竞品与价格：{competitors}
- 已有的成果证明：{proof}（案例、评价、数据；没有就写“无”）

## T 任务
1. 设计三档方案（入门 / 主推 / 高端），说明每档包含什么、为什么这样定价；
2. 写落地页：标题、副标题、痛点、解决方案、交付内容、价格、常见问题、行动按钮。

## O 输出
- 定价表：档位 | 价格 | 包含内容 | 设计意图
- 落地页文案（Markdown，按页面从上到下的顺序）
- 3 个可做 A/B 测试的标题

## R 规则
- 不编造评价、用户数和收入数据；{proof} 为“无”时，用过程透明和退款承诺建立信任，并标注需我确认。
- 不使用“月入十万”“躺赚”等夸大承诺。

## Y 验收标准
① 主推档最“划算”且最有吸引力；② 访客 10 秒内看懂“这是什么、给谁、多少钱”；③ 常见问题回应了 {objection}。
```

## Vic 实战提示

先把落地页做成一个免费页面测试点击，再决定是否投入制作产品。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
