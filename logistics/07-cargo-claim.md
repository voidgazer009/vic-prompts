# 货损货差索赔材料与索赔函

| 项目 | 内容 |
|---|---|
| 方向 | 🚢 国际物流 |
| 版本 | v1.0 · 2026-11-18 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |
| 灵感来源 | [vic-awesome-prompts · 延误索赔材料整理（JSON）](https://github.com/voidgazer009/vic-awesome-prompts/blob/main/collection/logistics/train-delay-claim.md)（CC0），改写为货损、货差、延误的货运索赔场景 |

## 用途

货物到港后发现破损、短少或严重延误时，把事实、证据和时效整理成一份索赔档案，并写好发给承运人 / 货代的索赔函，避免因为证据不全或错过时效而拿不到赔偿。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成真实信息（不知道的写“无”）；提单、条款可直接粘贴文字；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
把这票货的货损 / 货差 / 延误问题整理成可提交的索赔材料：事实时间线、证据清单、索赔金额表、索赔函，并提醒我哪些时效和步骤不能错过。目标是证据完整、数字有据、语气专业，提高拿到赔偿的概率。

## I 角色与受众
你是有 10 年经验的货运理赔专员，熟悉海运、空运的提单 / 运单、公估、保险索赔和承运人责任的一般流程。
结果给我（货主 / 货代 / 跨境卖家）看；索赔函发给承运人、货代或保险公司的理赔部门。

## C 背景
- 我的身份：{my_role}（货主 / 货代 / 跨境卖家）
- 货物与运输：{shipment_info}（品名、数量、起运港、目的港、运输方式、提单号 / 运单号、贸易条款）
- 问题类型：{issue_type}（破损 / 短少 / 受潮 / 延误 / 丢失）
- 发现的时间、地点与经过：{discovery}
- 货物价值与已有单证：{value_docs}（商业发票金额、保险单号、提单条款原文，没有就写“无”）
- 我手上的证据：{evidence}（开箱照片、封条号、公估报告、签收单批注、聊天记录）
- 对方目前的回应：{carrier_response}
- 我想要的结果：{goal}（全额赔偿 / 部分赔偿 / 先走保险）；邮件语言：{language}

## T 任务
1. 按时间顺序整理事实时间线（装货、开船、到港、提货、发现问题、通知对方），缺失的节点单列。
2. 检查证据是否够用：对照“问题类型”列出还缺的证据（如签收时的异常批注、封条照片、公估通知），并说明为什么需要。
3. 列出时效与程序风险：只引用我提供的提单条款和保险条款；没有提供的，写成“需向承运人 / 保险公司确认”。
4. 做索赔金额表：每一项标注“有凭证 / 估算 / 待确认”。
5. 判断先向谁索赔（承运人 / 货代 / 保险公司）的几种路径，并写出各自需要的材料，不替我下结论。
6. 写索赔函。

## O 输出
1. 结果行：“材料基本齐全”或“还缺 N 项关键材料”。
2. 事实时间线表：日期 | 事件 | 证据 | 状态。
3. 缺失证据与待确认事项清单（按紧急程度排序）。
4. 索赔金额表：项目 | 金额 | 币种 | 凭证 | 状态。
5. 索赔函：Subject + 正文（{language}，≤ 200 词），写明提单号、货物、问题、索赔金额和随附材料。
6. 下一步行动清单（谁做、做什么、何时前）。

## R 规则
- 金额、日期、条款只用我提供的材料，缺失写“未提供”，不要编造或估算，因为索赔函里一个对不上的数字会削弱整份材料的可信度。
- 不引用任何公约、法规或赔偿限额的具体数字，因为各条款和适用法律不同；需要时写“请向承运人或理赔顾问确认”。
- 不写“对方存在过错”这类定性结论，只陈述事实和证据，因为责任划分由条款、公估和对方答复共同决定。
- 不承诺“将起诉”“将投诉”等后果，除非我明确要求，因为这会让协商空间变窄。
- 索赔金额表里区分货值损失和间接损失，间接损失单独标注，因为很多条款不赔间接损失，混在一起会拖慢处理。
- 不要建议我销毁、涂改或补做原始证据，因为证据真实性是索赔的前提。
- 不在邮件里写银行账号、内部成本价和其他客户信息，因为这些属于敏感信息。

## Y 验收标准
① 时间线每个节点都有对应证据或标注缺失；② 金额表每一项都有状态标注；③ 没有出现我没提供的法规、限额或赔偿金额；④ 索赔函带提单号、金额和随附材料清单；⑤ 下一步清单有明确责任人和时间点。
```

## Vic 实战提示

提货时先在签收单上写异常批注并拍照，比事后补材料有用得多。拿到货当天就把照片、封条号和签收单发给 AI，让它先列缺失证据，再决定向谁索赔。

## 迭代指令（结果不满意时直接发）

- `保留结构，把索赔函改成更简短的版本，只保留提单号、问题、金额和附件清单。`
- `你以承运人理赔部门的身份读这封索赔函，指出最可能被拒绝的 2 个理由，并告诉我该补什么材料。`
- `把时间线和缺失证据整理成给公估人的一页说明。`
