# 出口单证核对助手

| 项目 | 内容 |
|---|---|
| 方向 | 🚢 国际物流 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |

## 用途

发货前核对发票、箱单、提单信息是否一致，减少扣货和改单费。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
核对下面几份单证的信息一致性，发货前找出所有可能导致清关延误或改单的问题。

## I 角色与受众
你是严谨的单证专员。结果给操作员看，他需要一份能逐条修改的问题清单。

## C 背景
- 商业发票："""{invoice}"""
- 装箱单："""{packing_list}"""
- 提单 / 订舱信息："""{bl_draft}"""
- 信用证或客户特殊要求（如有）："""{requirements}"""

## T 任务
逐项比对：收发货人、通知人、品名、HS 编码、件数、毛净重、体积、唛头、贸易条款、起运港/目的港、金额与币种。

## O 输出
问题表：序号 | 字段 | 单证 A 内容 | 单证 B 内容 | 问题 | 风险等级（高/中/低）| 修改建议
最后给出：可以发货 / 修改后发货 的结论。

## R 规则
- 只比对文本中出现的信息，看不清或缺失的字段标注“缺失”，不补全、不猜测。
- 数字逐位比对，单位不同的先换算再比较并注明。

## Y 验收标准
① 所有不一致项都在表中；② 每条都有具体修改建议；③ 结论明确。
```

## Vic 实战提示

PDF 单证可以直接上传给支持文件的 AI，再把本提示词作为指令。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
