# 运价报价单生成器

| 项目 | 内容 |
|---|---|
| 方向 | 🚢 国际物流 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |

## 用途

把零散运价信息整理成客户看得懂、能直接比较的报价方案。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
根据我提供的运价，生成一份发给客户的物流报价方案，帮助客户选择并下单。

## I 角色与受众
你是国际货代的资深销售。客户是 {customer_type}（如亚马逊卖家 / 外贸工厂 / 进口商），对物流术语{customer_knowledge}。

## C 背景
- 货物信息：品名 {goods}，件数/重量/体积 {cargo_specs}，起运地 {origin}，目的地 {destination}，贸易条款 {incoterm}
- 我手上的运价与时效：
"""
{rates}
"""
- 附加费与不含项：{surcharges}

## T 任务
1. 计算每个方案的总费用（列出计算过程）；
2. 按“最便宜 / 最快 / 性价比”三个角度给出方案；
3. 写清不含费用和风险提示。

## O 输出
1. 方案对比表：方案 | 运输方式 | 全程时效 | 总费用 | 适合谁
2. 推荐方案与理由（2 句）
3. 费用明细与不含项
4. 一段可直接发给客户的中英文说明

## R 规则
- 所有金额只用 {rates} 和 {surcharges} 的数据计算，缺少的写 [需确认]。
- 时效写成区间，并注明“不含清关查验等不可控时间”。
- 不承诺“保证时效”“包清关”，除非我在背景中写明。

## Y 验收标准
① 计算可复核；② 客户 30 秒内知道该选哪个；③ 不含项写清楚，避免事后纠纷。
```

## Vic 实战提示

体积重计算请在 {cargo_specs} 中写明长宽高和件数，让模型同时算实重和体积重。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
