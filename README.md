## 为什么有这个仓库

网上的提示词大多是通用模板，放到真实生意里就“不对味”。这里的每一条都来自 Vic 的四条业务线：

- 从姊妹仓库 **vic-awesome-prompts** 的全网精选中学习结构；
- 加入外贸、物流、一人公司、自媒体的真实业务背景和行业红线；
- 统一用 **VICTORY 七段式**重写，变量化，换个客户、换个产品就能复用。

## 怎么用

1. 找到你的场景，打开对应提示词；
2. 复制 Prompt，把 `{变量}` 换成你的信息；
3. 发给任意主流 AI（ChatGPT、Claude、Gemini、DeepSeek、Kimi、豆包）；
4. 不满意时用文末“迭代指令”修改。

想自己写？用 [VICTORY 模板](templates/VICTORY-template.md)，或直接用[元提示词](one-person-company/05-meta-prompt-builder.md)让 AI 帮你写。框架说明见 [FRAMEWORK.md](FRAMEWORK.md)。

## 质量标准

每条提示词上线前都满足：

- ✅ 七段齐全，变量清晰
- ✅ 写明“禁止编造”的边界（价格、数据、承诺、单号）
- ✅ 有可检验的验收标准
- ✅ 至少用 2 组真实信息测试过
