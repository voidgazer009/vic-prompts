# 🌍 外贸 · Foreign Trade

| # | 提示词 | 用途 |
|---|---|---|
| 01 | [开发信生成器（高回复率）](01-cold-email.md) | 给从未联系过的海外采购商写第一封邮件，目标是拿到回复，而不是直接卖货。 |
| 02 | [询盘分析与回复策略](02-inquiry-analysis.md) | 收到询盘后 2 分钟内判断真假、优先级，并写好第一封回复。 |
| 03 | [客户背调报告](03-buyer-research.md) | 联系客户前，把公开信息整理成一页背调，找到切入点。 |
| 04 | [价格谈判与异议处理](04-negotiation.md) | 客户说“太贵了”“别家更便宜”“交期太长”时，给出回应方案和回复邮件。 |
| 05 | [客户跟进序列（报价后不回复）](05-follow-up-sequence.md) | 报价后客户失联，生成 4 封节奏递进、每封都有新价值的跟进邮件。 |
| 06 | [尾款催收与账期风控](06-payment-chaser.md) | 货已出运、尾款不到时，理清账龄与风险，判断控单与信保时机，写出分级催款邮件。 |
