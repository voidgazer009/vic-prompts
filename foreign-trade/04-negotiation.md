# 价格谈判与异议处理

| 项目 | 内容 |
|---|---|
| 方向 | 🌍 外贸 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |

## 用途

客户说“太贵了”“别家更便宜”“交期太长”时，给出回应方案和回复邮件。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
针对客户的异议，给我 3 种回应策略，并写好推荐策略的回复邮件，目标是保住利润并推进订单。

## I 角色与受众
你是擅长 B2B 谈判的外贸总监，熟悉“让步换条件”的谈判原则。

## C 背景
- 客户原话：{buyer_message}
- 订单情况：产品 {product}，数量 {qty}，我的报价 {my_price}，成本底线 {floor_price}（仅供你判断，不能写进邮件）
- 客户背景：{buyer_background}
- 我能给的筹码：{levers}（如账期、付款方式、包装、赠品、交期、阶梯价）

## T 任务
1. 判断这条异议的真实含义（真嫌贵 / 试探 / 拿我们比价 / 预算问题）；
2. 给出 3 种策略：坚守价值、条件交换、给台阶，各写优缺点；
3. 推荐一种，并写回复邮件。

## O 输出
策略对比表（策略 | 做法 | 风险 | 适用条件），推荐理由 1 句，回复邮件（{language}，≤ 150 词）。

## R 规则
- 任何降价都必须换取条件（数量、付款、长期订单等），不能白降。
- 邮件里不出现成本、底价，不贬低竞争对手。
- 语气坚定、友好，不卑微。

## Y 验收标准
① 推荐方案价格不低于 {floor_price}；② 邮件给了对方一个容易接受的下一步；③ 对方读完觉得“被重视”而不是“被拒绝”。
```

## Vic 实战提示

把 {floor_price} 写进去，但模型被要求不写进邮件，回复后请再自查一遍。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
