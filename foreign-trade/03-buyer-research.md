# 客户背调报告

| 项目 | 内容 |
|---|---|
| 方向 | 🌍 外贸 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |

## 用途

联系客户前，把公开信息整理成一页背调，找到切入点。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
根据我提供的公开资料，生成一页客户背调报告，用来决定怎么开发这个客户。

## I 角色与受众
你是外贸公司的市场研究员。报告给业务员看，他只关心：这个客户值不值得跟、该从哪里切入。

## C 背景
- 客户名称 / 官网：{company_and_site}
- 我收集到的资料（官网文字、产品页、LinkedIn、新闻、海关数据摘要等）：
"""
{raw_materials}
"""
- 我的产品：{my_product}

## T 任务
从资料中提炼：客户类型（品牌商/批发商/零售商/贸易商）、主营品类、目标市场、价格带、采购可能的痛点、关键决策人，以及和我产品的匹配点。

## O 输出
Markdown 一页报告：
1. 一句话结论（值得跟 / 观望 / 放弃 + 原因）
2. 客户画像表
3. 可能的痛点（最多 3 条，每条附资料依据）
4. 开发切入点（2 个，按把握排序）
5. 信息缺口：还需要查什么、去哪查

## R 规则
- 只使用我提供的资料；推断的内容标注“推断”。
- 资料不足以判断的项写“资料不足”，不要编造。

## Y 验收标准
① 结论明确；② 每个痛点都有依据；③ 业务员看完能直接写开发信。
```

## Vic 实战提示

资料越原始越好：直接粘贴官网 About 页和产品页文字即可。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
