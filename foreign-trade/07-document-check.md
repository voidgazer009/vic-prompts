# 出运单据一致性核对（CI / PL / 提单 / 合同）

| 项目 | 内容 |
|---|---|
| 方向 | 🌍 外贸 |
| 版本 | v1.0 · 2026-11-17 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |
| 灵感来源 | [vic-awesome-prompts · 发票数字与完整性核对](https://github.com/voidgazer009/vic-awesome-prompts/blob/main/collection/foreign-trade/invoice-checker.md)（CC0），扩展为多单据交叉核对，加入外贸出运与结汇场景 |

## 用途

出运前或交单前，把商业发票、装箱单、合同 / PI、提单样本（或订舱确认）的内容交叉核对，找出金额、数量、重量、品名、贸易术语、收货人信息不一致的地方，避免客户拒付、清关延误或信用证不符点。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成真实内容（敏感的银行账号可以不贴）；
3. 发送给 AI。结果不满意时用文末迭代指令修改。

## Prompt

```markdown
## V 目标
在出运 / 交单之前，把这一单的几份单据交叉核对一遍，列出所有不一致和缺失，让我能在发给客户、货代或银行之前改掉。

## I 角色与受众
你是有 10 年经验的外贸单证员，熟悉商业发票、装箱单、提单、合同 / PI 的常见错误，以及 L/C 下“单证相符”的基本要求。
结果给我（业务员 / 跟单）看，要能直接按清单逐项修改。

## C 背景
- 付款方式：{payment_terms}（T/T / L/C / D/P 等）
- 贸易术语：{incoterm}
- 币种：{currency}
- 如果是 L/C，信用证中对单据的要求原文：{lc_clauses}（T/T 写“无”）
- 合同 / PI：
"""
{contract_or_pi}
"""
- 商业发票：
"""
{commercial_invoice}
"""
- 装箱单：
"""
{packing_list}
"""
- 提单样本或订舱确认：
"""
{bl_draft}
"""

## T 任务
1. 从每份单据提取：买卖双方名称与地址、单据号与日期、品名与规格、数量与单位、单价、行金额、总金额、币种、贸易术语与地点、件数、毛重、净重、体积、唛头、起运港与目的港。
2. 重新计算：发票每行（数量 × 单价）、合计金额、装箱单各行与总计的件数、毛重、净重、体积。
3. 逐项交叉比对同一信息在不同单据中的写法，列出所有不一致，包括拼写、大小写、单位、日期先后。
4. 若有 L/C 条款，逐条核对是否满足，列出可能的不符点。
5. 列出缺失或不清楚的信息，以及需要我向客户或货代确认的问题。

## O 输出
1. 结论行：“全部一致”或“发现 N 处不一致”。
2. 差异表：项目 | 单据 A 写法 | 单据 B 写法 | 差异 | 建议以哪份为准（只写“需确认”或依据合同的建议）。
3. 计算核对表：项目 | 单据所写 | 重算结果 | 差额。
4. L/C 条款核对表（无 L/C 则省略）：条款 | 满足 / 不满足 / 无法判断 | 依据。
5. 需要确认的问题清单。

## R 规则
- 数字只用我提供的单据内容，缺失写“未提供”，不要估算或补全，因为单据上一个编造的数字就可能导致拒付。
- 计算要写出算式；如果你能运行代码就用精确小数并说明，不能就写明是手算需要复核，因为你心算的合计容易出错。
- 不要静默修改任何单据，只列差异，因为以哪份为准要由合同和我决定。
- 不给税务、海关归类、法律或退税结论，只提示“请向报关行或专业人士确认”，因为这些取决于你不了解的具体情况。
- 品名、数量、金额等写法差异，哪怕只是大小写或标点，也要列出，但标注严重程度（高 / 中 / 低），因为 L/C 下细小差异也可能被银行视为不符点。
- 不要推断我没说的合同条款，不要承诺银行一定接受或拒绝，因为是否接受由银行判断。

## Y 验收标准
① 每处差异都写明出现在哪两份单据及两边的原文；② 所有重算结果带算式；③ 有 L/C 时每条条款都有判断和依据；④ 没有出现我没提供的数字；⑤ 问题清单我可以直接发给客户或货代。
```

## Vic 实战提示

先让业务、跟单各自出单据，再统一贴进来核对，别等订舱截关前一小时才做。每次核对出来的新类型错误，记到自己的单据模板里，同类错误第二次就不会再犯。

## 迭代指令（结果不满意时直接发）

- `只保留严重程度为高的差异，按“先改哪个”排序。`
- `根据差异表，写一封给客户确认信息的邮件（英文，≤ 120 词），一次问完所有问题。`
- `再按“客户清关会看的字段”核一遍：品名、数量、重量、原产国、收货人。`
