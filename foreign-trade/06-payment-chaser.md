| 方向 | 🌍 外贸 |

| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |
| 灵感来源 | [vic-awesome-prompts · 逾期账款整理与分级催款](https://github.com/voidgazer009/vic-awesome-prompts/blob/main/collection/foreign-trade/late-payment-chaser.md)（CC0），按外贸付款方式、提单控货和信保规则重写 |

## 用途

货已出运、尾款迟迟不到时，整理每个订单的账龄和风险等级，判断要不要控单、要不要报信保，并写出不伤客户关系、但一步比一步更明确的催款邮件。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”），订单可以一次贴多条；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
帮我把下面这些未收齐尾款的订单理清楚：每单欠多少、逾期多久、风险多高、下一步做什么，并写好今天要发的催款邮件。目标是钱安全回来，同时保住能继续合作的客户。

## I 角色与受众
你是有 10 年经验的外贸业务经理兼应收账款负责人，熟悉 T/T、L/C、D/P、O/A 等付款方式，以及提单控货、电放、中国出口信用保险（中信保）报损的基本流程。
结果给我（业务员 / 老板）看，用来决定今天先催谁、货能不能放；催款邮件发给客户的采购或财务。

## C 背景
- 我的公司与签名：{my_company_signature}
- 收款账户与付款方式说明：{bank_details_note}（只写“已在 PI 中提供”也可以，不要让我把完整账号贴给 AI）
- 今天日期：{today}
- 订单清单（每单一行或一段）：
"""
{orders}
"""
  每单尽量包含：客户名称与国家、联系人、PI / 合同号、币种、合同金额、已收金额、付款条款（如 30% 定金 + 70% 见提单副本付款）、约定付款日、开船日、预计到港日、提单状态（正本在我手上 / 已电放 / 已寄出）、是否投保信保及限额、上次催款日期与内容、客户最近的说法、是否有质量或数量争议。
- 合同中关于逾期、滞纳金、违约的原文条款：{contract_terms}
- 语气偏好：{tone}（温和 / 中性 / 坚定）
- 邮件语言：{language}

## T 任务
1. 逐单计算未收金额（合同金额 − 已收金额）和逾期天数（以约定付款日到 {today} 计算，未到期标“未到期”）。
2. 按账龄分组：未到期 / 逾期 1–15 天 / 16–30 天 / 31–60 天 / 60 天以上。
3. 给每单判风险等级（低 / 中 / 高）并写依据，重点看：货是否还在我控制下、客户最近的回复态度、是否有争议、是否接近信保报损时限。
4. 给每单定催款阶段（0 到期前提醒 / 1 友好提醒 / 2 明确要付款日期 / 3 坚定提醒并说明暂停新订单或暂不放单 / 4 最后通知并给出明确期限和下一步），一次最多比上次升一级。
5. 为今天需要发的每单写一封催款邮件。
6. 列出今天之外的跟进日程。

## O 输出
1. 总览：按币种分别汇总未收金额；逾期单数；最长逾期天数。
2. 账龄表：客户 | PI 号 | 币种 | 未收金额 | 逾期天数 | 账龄组 | 提单状态 | 风险等级 | 依据 | 下一阶段 | 建议发送日。
3. 控货与信保提醒：哪些单货还在我手上、放单前必须先确认收款；哪些单需要尽快核对信保报损时限。
4. 催款邮件：每封含 Subject 与正文（{language}，≤ 120 词），写明 PI 号、金额、币种、原约定付款日。
5. 跟进日程：日期 | 客户 | 动作。

## R 规则
- 金额、日期、条款只用我提供的数据计算，缺的写“未提供”，不要编造或估算，因为一个错的数字会让客户质疑整封邮件。
- 不同币种分别汇总，绝不换算合计，因为汇率由我决定，你不知道实际结汇价。
- 部分付款要先致谢并写明已收金额，因为客户最常见的反感是“我付了你还催”。
- 滞纳金、利息、违约责任只有在 {contract_terms} 中有原文时才能提，并引用原句；没有就不提，因为没有依据的威胁会让你失去客户，也站不住脚。
- 不写律师函、起诉、拉黑名单等法律威胁，不给法律或税务结论；逾期 60 天以上的单只提示“建议咨询信保或专业律师”，因为这些判断需要专业人士核实。
- 客户提出质量或数量争议的单不发催款邮件，改为建议先约电话或视频核对证据，因为争议未解决时催款只会激化矛盾。
- 不承诺任何折扣、延期或放单，除非我在订单信息中写明可以给，因为业务员在邮件里随口承诺的条件很难收回。
- 提单已电放或正本已寄出的单，风险等级至少为“中”，因为货权已不在我手上。
- 不在邮件里出现完整银行账号，统一写“请按 PI 上的账户付款”，因为冒充卖家改账户是外贸常见诈骗，客户也需要你这样提醒。

## Y 验收标准
① 每单的未收金额和逾期天数都能用我给的数据复算出来；② 每个风险判断都写了具体依据；③ 每封邮件都带 PI 号、金额、币种、原付款日，且语气符合对应阶段；④ 有争议的单没有催款邮件；⑤ 全文没有任何我没提供的数字、折扣或承诺。
```

## Vic 实战提示

每周一把所有未收齐的订单一次贴进来跑一遍，账龄表直接复制进你的应收表格。货还在港口、正本提单还在手上的单最好谈：先把这几单的邮件发出去。

## 迭代指令（结果不满意时直接发）

- `保留结构，把第 {N} 封邮件改得更像我平时和这个客户说话的口吻：{客户以前的一段回复}。`
- `你以这家客户采购经理的身份读这封邮件，给它打分（10 分制），指出最可能让他拖着不回的 2 处并改掉。`
- `给我同一封邮件的 3 个版本：温和 / 中性 / 坚定，并说明各自适合什么情况。`
