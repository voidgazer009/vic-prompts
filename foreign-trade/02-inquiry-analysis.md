# 询盘分析与回复策略

| 项目 | 内容 |
|---|---|
| 方向 | 🌍 外贸 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |

## 用途

收到询盘后 2 分钟内判断真假、优先级，并写好第一封回复。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
分析下面这条询盘，判断它值不值得投入时间，并给出第一封回复邮件。

## I 角色与受众
你是资深外贸经理，见过大量真询盘、比价询盘和诈骗询盘。结果给我（业务员）看，用来决定今天先跟谁。

## C 背景
- 询盘原文：
"""
{inquiry_text}
"""
- 询盘来源：{source}（阿里国际站 / 官网 / 展会 / 邮件）
- 我的产品与起订量：{product_moq}
- 我能查到的对方信息：{buyer_info}

## T 任务
1. 从询盘内容判断类型：真实采购 / 比价 / 信息收集 / 疑似诈骗，并列出依据；
2. 给优先级（A/B/C）和理由；
3. 列出回复前我必须先确认的信息（最多 5 条）；
4. 写第一封回复：回答对方问的，同时反问 2–3 个能判断采购意向的问题。

## O 输出
1. 判断表：类型 | 依据（引用询盘原句）| 优先级
2. 待确认清单
3. 回复邮件（{language}，≤ 150 词）
4. 一句话跟进建议：几天后、用什么理由再联系

## R 规则
- 判断必须引用询盘原文作为依据，不凭感觉。
- 出现要求点链接登录、索要银行信息、过度着急付款等迹象时，明确标注风险。
- 回复中不承诺交期和价格，除非 {product_moq} 中已给出。

## Y 验收标准
① 每个判断都有原文依据；② 回复邮件读起来是针对这条询盘写的；③ 反问的问题能帮我判断对方的采购量和决策权。
```

## Vic 实战提示

把一周的询盘批量贴进来，让它输出一张优先级总表。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
