# 大号评论区借势引流评论

| 项目 | 内容 |
|---|---|
| 方向 | 📱 自媒体运营 |
| 版本 | v1.0 · 2026-11-20 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |
| 灵感来源 | [vic-awesome-prompts · LinkedIn 真人感评论生成器](https://github.com/voidgazer009/vic-awesome-prompts/blob/main/collection/social-media/linkedin-comments.md)（CC0），按中文平台、业务线口吻和引流红线重写 |

## 用途

去同行、客户、行业大号的帖子下留言时，先问清帖子语境，再写出有人味、有信息量、不像广告的评论，让作者和围观的人点进你的主页。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI，先回答它提的问题，再拿评论；结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
帮我在别人的帖子下写评论，让作者愿意回复、围观者愿意点进我的主页。评论要有真实的观点或信息，不是客套，也不是广告。

## I 角色与受众
你是熟悉 {platform} 的内容运营，擅长用一两句话说出有价值的观点。
评论的读者是帖子作者和刷到评论区的潜在同行、客户；他们对广告和套话很敏感。

## C 背景
- 我是谁（业务与真实经历）：{my_background}
- 我的说话风格（口头禅、常用比喻、语气）：{my_style}
- 我绝不会说的话或不想出现的套路：{banned_phrases}
- 评论目的：{goal}（建立关系 / 被作者注意到 / 引导点主页 / 单纯互动）
- 帖子内容：
"""
{post_text}
"""
- 帖子作者与我的关系：{relationship}

## T 任务
1. 先问我 3 到 5 个关于这条帖子的简短问题（例如：我对这个观点的真实态度、我有没有相关亲身经历、作者是不是熟人），已能从上面信息判断的不要问。等我回答后再继续。
2. 判断这条帖子适合的互动类型：补充信息 / 友善质疑 / 分享经验 / 提问 / 轻松调侃。
3. 写三条评论：直接实用型、轻幽默型（帖子严肃时改为共鸣型并说明原因）、有思考型。
4. 每条评论后用一句话说明它的作用和可能得到的回应。

## O 输出
- 第一轮只输出问题清单，不输出评论。
- 第二轮输出：互动类型判断（一句话）；三条评论，每条 {max_chars} 字以内，附作用说明。
- 最后问我：“发哪一条？”

## R 规则
- 只写我提供或回答过的经历、数据和观点，不编造个人经历、客户案例或数字，因为评论区的人会追问，编的内容一戳就破。
- 评论里不放链接、联系方式、产品名和“欢迎私信”，除非 {goal} 明确要求，因为多数平台会把这类评论判为营销并限流或折叠。
- 不写“学到了”“太棒了”“感谢分享”这类可以贴在任何帖子下的话，因为它们不会让作者记住你。
- 不贬低作者或其他评论者，质疑时先承认对方说得对的部分，因为在别人的评论区起冲突，吃亏的是后来者。
- 帖子涉及灾难、疾病、个人困境时不用玩笑和营销口吻，因为蹭这类话题会直接伤害账号形象。
- 不涉及政治、投资建议和对竞品的指名批评，因为这类评论风险高于收益。

## Y 验收标准
① 每条评论都只能放在这一条帖子下，换一条帖子就不成立；② 没有任何我没提供的经历或数字；③ 没有链接、联系方式和套话（{goal} 要求的除外）；④ 三条风格明显不同；⑤ 读起来像我平时说话，而不是运营话术。
```

## Vic 实战提示

每天固定花 15 分钟，挑 3 个目标账号的最新帖子各评一条，比发一条普通内容更容易被看见。评论发出后的前 1 小时留意回复，作者回你了就接着聊两轮，再考虑要不要互相关注。把你满意的评论存起来，下次放进 {my_style} 当范例。

## 迭代指令（结果不满意时直接发）

- `保留结构，把第 {N} 条评论改得更像我这条旧评论的口吻：{我以前写的一条评论}。`
- `你以帖子作者的身份读这三条评论，哪一条最可能让你点进我的主页？说明理由，并把它改得更好。`
- `这条帖子下已经有 {N} 条高赞评论：{高赞评论}，帮我写一条和它们角度不同、不重复的评论。`
