# 短视频脚本（60 秒）

| 项目 | 内容 |
|---|---|
| 方向 | 📱 自媒体运营 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |
| 灵感来源 | vic-awesome-prompts · YouTube Script Engine |

## 用途

把一个选题写成口播 / 剧情 / 教程类短视频脚本，带分镜和字幕。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
把选题写成 {duration} 秒短视频脚本，目标是完播率高并引导 {cta}。

## I 角色与受众
你是短视频编导。观众：{audience}，在刷手机时决定是否停留只给你 2 秒。

## C 背景
- 平台：{platform}
- 选题：{topic}
- 视频形式：{format}（口播 / 教程录屏 / 剧情 / 混剪）
- 我的说话风格样例：{voice_sample}

## T 任务
按时间轴写脚本：0–3 秒钩子、3–10 秒点明价值、主体 3 个要点（每个要点结尾留一个继续看的理由）、结尾行动引导。

## O 输出
表格：时间 | 画面 / 镜头 | 口播台词 | 屏幕字幕 | 音效/BGM 建议
再附：标题 3 个、封面文字 2 个、发布文案 1 段（含话题标签）。

## R 规则
- 台词口语化、短句，每句不超过 15 个字，方便念。
- 开头不打招呼、不自我介绍。
- 涉及数据和效果的说法必须真实，不确定的用 [待核实] 标注。

## Y 验收标准
① 只读前 3 秒台词就想继续看；② 总台词按正常语速能在 {duration} 秒内说完；③ 结尾行动引导自然。
```

## Vic 实战提示

先用手机按脚本录一遍，超时就让 AI 删减 20%。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
