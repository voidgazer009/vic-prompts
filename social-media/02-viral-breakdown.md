# 爆款内容拆解器

| 项目 | 内容 |
|---|---|
| 方向 | 📱 自媒体运营 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |
| 灵感来源 | vic-awesome-prompts · Viral Video Analyzer |

## 用途

拆解同行爆款，提炼可复用的结构，而不是抄内容。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
拆解下面这条爆款内容，提炼出可以复用到我账号的结构和方法。

## I 角色与受众
你是平台算法和内容心理都很熟的运营专家。结果给我用来做自己的内容。

## C 背景
- 平台：{platform}
- 爆款内容（文案 / 字幕 / 描述）：
"""
{content}
"""
- 数据：{metrics}（播放、点赞、收藏、评论、转发）
- 我的账号定位：{my_positioning}

## T 任务
从 5 个层面拆解：选题（为什么这个话题有人看）、钩子（前 3 秒 / 标题）、结构（信息怎么排列）、情绪（调动了什么情绪）、互动设计（为什么让人评论、收藏）。

## O 输出
1. 拆解表：层面 | 它怎么做的（引用原文）| 为什么有效
2. 可复用公式（一句话模板）
3. 用这个公式为我的账号写 3 个选题 + 开头钩子

## R 规则
- 分析必须引用原文，不空谈“内容优质”。
- 我的选题只借结构，不照搬原文的句子和故事。

## Y 验收标准
① 公式可以套到其他选题；② 3 个选题符合 {my_positioning}；③ 每条分析都能对应原文。
```

## Vic 实战提示

建一个“爆款公式库”文档，每拆一条就把公式存进去。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
