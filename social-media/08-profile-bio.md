## 用途

别人点进你的主页的 3 秒内决定关不关注、私不私信。先诊断现有简介哪里在劝退，再写三版不同打法的简介和置顶内容建议。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI，拿到结果后用文末迭代指令微调。

## Prompt

```markdown
## V 目标
重写我在 {platform} 的主页简介，并给出置顶内容建议，让目标受众在几秒内看懂我是谁、能帮他什么、下一步该做什么。

## I 角色与受众
你是熟悉 {platform} 的个人品牌运营。
读者是 {target_audience}，他们只会扫一眼，对夸大和空话没有耐心。

## C 背景
- 我的业务与定位：{my_business}
- 我能拿出的真实成果和证明（只列真的）：{proofs}
- 现有简介：{current_bio}
- 现有置顶或代表作：{pinned_posts}
- 希望对方做的下一步：{cta}（关注 / 私信 / 看置顶 / 加微信等）
- 字数或字符限制：{limit}
- 不想出现的说法：{banned_phrases}

## T 任务
1. 诊断现有简介：指出 3 个最影响转化的问题（身份不清、没有受众、没有证明、没有下一步等）。
2. 写三版简介：定位型（一句话讲清帮谁解决什么）、证明型（以我提供的成果为主）、人设型（有个性、好记）。
3. 对置顶内容给出建议：保留哪条、替换成什么类型的内容，只说类型和选题方向，不编造内容数据。
4. 指出我还缺哪些证明材料，列出补充清单。

## O 输出
- 诊断：3 条，每条一句话。
- 三版简介：每版不超过 {limit}，下面一行写适合的读者和风险。
- 置顶建议：最多 3 条。
- 缺失证明清单。

## R 规则
- 成果、客户、数字只用我在 {proofs} 里给的，不编造，不夸大，因为主页内容会被对方核实，一次被发现造假就失去信任。
- 不写“全网第一”“最专业”“保证出单”“稳赚”等绝对化或收益承诺用语，因为平台会限流，广告法也不允许。
- 不放个人隐私、未授权的客户名和第三方联系方式，因为这会带来合规和安全风险。
- 联系方式和引流方式必须符合 {platform} 的规则；不确定的写“按平台规则替换”，因为违规引流会被降权或封号。
- 每版简介只表达一个核心卖点，因为扫读时的读者记不住第二个。
- 信息不足时先列出需要我补充的问题，不自己补全。

## Y 验收标准
① 陌生人读完能说出我帮谁、解决什么；② 每个数字和案例都能在我提供的资料里找到；③ 没有绝对化用语和收益承诺；④ 三版明显不同；⑤ 有且只有一个明确的下一步动作。
```

## Vic 实战提示

每个季度重写一次简介，同时把置顶换成最近数据最好的一条。先把你的真实成果清单整理好再用，AI 能写的只是排版和措辞，证明材料得你自己有。换版后观察一周的主页访问到关注转化率，再决定留哪版。

## 迭代指令（结果不满意时直接发）

- `保留第 {N} 版，把受众收窄到 {更具体的受众}，重写一版。`
- `你作为 {target_audience} 的一员，用 3 秒扫读这版简介，说你记住了什么、没看懂什么，再据此修改。`
- `把第 {N} 版压缩到 {数字} 字以内，保留身份和下一步动作。`
