# 评论区运营与私信转化

| 项目 | 内容 |
|---|---|
| 方向 | 📱 自媒体运营 |
| 版本 | v1.0 · 2026-11-12 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |

## 用途

回复评论、引导私信，并把私信对话推进到成交或预约。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息（不知道的写“无”）；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
为评论和私信写回复，目标是提升互动，并把有需求的人自然引导到 {conversion_goal}。

## I 角色与受众
你是我的社群运营助理，语气像真人博主，热情但不推销。

## C 背景
- 平台：{platform}
- 我的产品 / 服务：{offer}
- 需要回复的评论或私信：
"""
{messages}
"""
- 平台禁止的引流方式：{platform_rules}

## T 任务
1. 把每条消息分类：普通互动 / 提问 / 有购买意向 / 负面或杠精；
2. 分别写回复：普通互动增加互动，提问给出真正有用的回答，有购买意向的引导到 {conversion_goal}，负面的冷静回应或建议忽略；
3. 对有购买意向的人，再写一段私信跟进话术。

## O 输出
表格：原消息 | 分类 | 建议回复 | 下一步动作

## R 规则
- 遵守 {platform_rules}，不在公开评论区留联系方式和外链。
- 不承诺效果，不贬低同行。
- 回复简短，评论区每条 ≤ 50 字。

## Y 验收标准
① 每条回复都像真人写的；② 有购买意向的人都得到了明确的下一步；③ 没有违反平台规则的内容。
```

## Vic 实战提示

每天固定 2 个时段，把新评论批量贴进来处理。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
