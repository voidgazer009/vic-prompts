# 爆款发布后复盘与迭代

| 项目 | 内容 |
|---|---|
| 方向 | 📱 自媒体运营 |
| 版本 | v1.0 · 2026-11-16 |
| 结构 | VICTORY 七段式 |
| 适用模型 | ChatGPT / Claude / Gemini / DeepSeek / Kimi / 豆包 等 |
| 灵感来源 | [TikTok / 小红书爆款视频拆解](https://github.com/voidgazer009/vic-awesome-prompts/blob/main/collection/social-media/viral-video-analyzer.md)（CC0，已大幅改写） |

## 用途

用你自己账号的真实后台数据，复盘最近发布的内容：哪条该加推、哪条该改、哪条该停，并给出下一周的具体实验。

## 使用方法

1. 复制下面整段提示词；
2. 把 `{花括号}` 里的变量换成你的真实信息，后台数据直接粘贴，不知道的写“无”；
3. 发送给 AI。结果不满意时，用文末的迭代指令修改，不要重写。

## Prompt

```markdown
## V 目标
基于我提供的真实数据，复盘近期内容表现，找出可复制的规律，并定出下一周 3 个可验证的实验。

## I 角色与受众
你是我的内容数据分析师，只信数据，不迎合我。结果只给我自己看，说话直接。

## C 背景
- 平台：{platform}
- 账号定位与变现目标：{positioning}
- 近期内容及后台数据（标题、发布时间、播放/曝光、完播率、点赞、评论、收藏、转发、涨粉、私信数，有什么给什么）：
"""
{post_data}
"""
- 我自己的判断（可选）：{my_hypothesis}

## T 任务
1. 先检查数据是否够用：样本少于 {min_posts} 条或缺关键指标时，明确说明结论只是方向性的；
2. 按“曝光、完播、互动、转化”四个环节，找出每条内容的最大流失点；
3. 把内容分成“加推 / 改写重发 / 停止”三类，每条给出依据；
4. 总结最多 3 条跨内容的共同规律，并标注证据来自哪几条；
5. 设计下一周 3 个实验：每个写明改动的单一变量、预期观察的指标、判断成败的标准。

## O 输出
① 数据充分度判断；② 分类表（内容 | 类别 | 最大流失点 | 依据）；③ 共同规律；④ 三个实验（变量 | 指标 | 成败标准）。

## R 规则
- 只使用我提供的数据，缺失的指标写“未提供”，禁止编造播放量、完播率、行业均值或他人爆款数据，因为编造的基准会让我做出错误决策。
- 样本小时不下因果结论，只说“可能”，因为单条内容的波动很大，一次爆或不爆说明不了规律。
- 每个实验只改一个变量，因为同时改多处就无法知道是什么起了作用。
- 不建议刷量、买粉、搬运他人内容或违反平台规则的做法，因为会带来限流和封号风险。
- 不承诺涨粉或变现效果。

## Y 验收标准
① 每个结论都能指回具体某条内容的某个数字；② 没有出现我未提供的数据；③ 三个实验都能在一周内执行并判断成败。
```

## Vic 实战提示

每周固定一天复盘，至少攒够 8 到 10 条再看规律。数据从平台后台复制，不要凭印象写。

## 迭代指令（结果不满意时直接发）

- `保留结构，每一条都换成更具体的例子、数字或场景。`
- `你以目标读者的身份给它打分（10 分制），指出最弱的 3 处并改掉。`
- `给我 3 个风格差异明显的版本，并说明各自适合什么情况。`
